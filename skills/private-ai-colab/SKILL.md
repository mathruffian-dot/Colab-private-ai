# 教師私人 AI：一鍵完成（Agent 模式）

用內建瀏覽器（`mcp__Claude_Browser__*`）操作 Colab，老師只在 Google 登入、服務條款兩處親自點按，其餘全部由你完成。

依使用者的話決定從哪一段開始：

| 使用者說 | 執行 |
|---|---|
| 啟動私人 AI／開 Colab／第一次連 Colab | A → B → C |
| 私人 AI 用完了／關掉私人 AI／關掉 Colab | D → E |
| 還有沒有在扣單元 | E |

## 固定設定

- 筆記本（正式版，GitHub）：`https://colab.research.google.com/github/mathruffian-dot/Colab-private-ai/blob/main/啟動私人AI.ipynb`
  - 特性：預設 G4；Strata 上下文 256K；OpenCode 固定 1.19.4、用到 80% 自動壓縮；入口直接開進「工作區」新對話；背景預裝文件工具（OCR 繁中、PDF、Word／Excel／PowerPoint、表格與圖表：Excel／PPT 原生圖表、matplotlib／seaborn／plotly、graphviz 流程圖、合併列印、PDF／Office 加密、掃描 PDF 轉文字、標楷體／新細明體對應、簡轉繁、FFmpeg／ImageMagick、語音轉文字（faster-whisper 離線）、文字轉語音（edge-tts 線上，限非個資）、QR code／注音／文字雲、7z／unar，中文字型已設定），第 ④ 格開機自我檢查（20 項）；思考強度 off／low／medium／high；「👀 檢視工作區檔案」格；不儲存輸出；「全部執行」停在 ⏹ 格。
  - 從 GitHub 開啟會出現「這個筆記本不是由 Google 編寫的」，按「仍要執行」。
- 筆記本由 `tools/build_notebook.py` 從 `colab/` 產生；修改後重產並 push 到 GitHub（網址不變）。
- 費用：G4 約 8.7 運算單元／小時。**只有「中斷連線並刪除執行階段」才會停止扣單元**，關分頁不會。

## 隱私硬規則（不可違反）

1. 入口交給老師後，**不得截圖、讀取或操作入口（第 ⑤ 格下方的內嵌畫面）**，也不得讀取工作區檔案。
2. 只讀第 ①～④ 格輸出、清理格輸出、工作階段對話框。
3. 不得在 Colab 啟用 Gemini／AI 自動完成；跳出提示一律按 ✕。
4. 不代輸入 Google 密碼、不代按服務條款「同意」、不代付款或升級方案——遇到就停下來請老師處理。
5. 回報時不要複述老師的 Email 等帳號資訊，只說「已登入」。

## 操作技巧（實測經驗）

- 按鈕優先用 `find` 取得 ref 再點；窗格大小會變，不要沿用舊截圖的座標。
- 找不到 ref 的元件（核取方塊、儲存格 ▶、確認對話框「是」、方案頁的「目前方案」標籤）：先 `scroll_to`／截圖，依**當下截圖**判讀或點擊，點完用 `zoom` 確認。
- 工具列的「全部執行」用 `find` 會拿到隱藏的選單項目；改成先點「執行階段」選單，再點選單裡的「全部執行」。
- 快捷鍵（Ctrl+F10 等）在窗格裡不一定生效，優先用選單項目。
- 「全部執行」會停在「⏹ 啟動完成」格（顯示紅色停止標記是正常的），上傳／下載／清理格不會自動執行。
- 讀儲存格輸出：
  ```js
  [...document.querySelectorAll('div')].filter(e => (e.getAttribute('aria-label')||'').endsWith('輸出區域')).map(o => o.getAttribute('aria-label') + ' :: ' + o.innerText.slice(-250).replace(/\n/g,' | ')).join('\n')
  ```
- 等待：`browser_batch` 串多個 10 秒 `wait`（單次約 3 分鐘上限）。
- 請老師在瀏覽器窗格操作前，先 `tabs_context` 確認窗格有顯示；隱藏時請老師按 Ctrl+Shift+B 叫出來。
- 內建瀏覽器開不了新分頁、不顯示帳密框；入口是內嵌在筆記本裡，不需要新分頁。

## A. 首次連線檢查（每次啟動都跑，已就緒會很快通過）

1. `preview_start` 開 `https://colab.research.google.com/`。
2. **登入**：`find`「Google 帳戶」。
   - 找得到（按鈕名稱含「Google 帳戶：…」）→ 已登入，繼續。
   - 找不到、或出現「登入」→ 停下來，請老師：「請在瀏覽器窗格（Ctrl+Shift+B）右上角按『登入』，用**有付費 Colab 運算單元**的 Google 帳號登入，好了告訴我。」老師回覆後重新檢查。
   - 已登入但老師說帳號不對 → 請老師點右上角頭像切換帳號。
3. **方案**：`navigate` 到 `https://colab.research.google.com/signup`，截圖找「目前方案」標籤在哪張卡片：
   - 在 Google AI Plans／Colab Pro／Pro+／Pay As You Go → 有付費方案，繼續。
   - 只在免費方案、或看不到 → 停下來說明：「免費版不能跑這個工作流（不允許網頁介面、GPU 不足）。需要 Google AI Pro 或 Colab Pro。」不要代為購買。
4. 開筆記本網址。
   - 出現〈服務條款〉對話框 → 停下來，請老師自己按「同意」。
   - 從 GitHub 開啟出現「這個筆記本不是由 Google 編寫的」→ 老師要求啟動即表示要執行這本筆記本，可按「仍要執行」；網址不是上面固定網址就先問老師。
5. 確認工具列右上顯示 **G4**（筆記本已預設）；不是的話請老師到「執行階段 → 變更執行階段類型」選 G4。
6. 檢查有沒有遺留主機在扣單元：`find`「執行階段」→ 開選單 → `find`「管理工作階段」→ 點擊 → 截圖。
   - 「沒有作用中工作階段」→ 按 Esc 關閉，繼續。
   - 有其他工作階段 → 告訴老師（不要說檔名以外的內容），問要不要先終止；老師同意才按「終止」。

## B. 啟動

1. 告訴老師：要開一台 G4（約 8.7 單元／小時），約 10 分鐘可用。
2. `find`「執行階段」→ 點選單 → `find`「全部執行」→ 點選單項目。跳出 AI 自動完成提示 → 按 ✕。
3. 每 2–3 分鐘讀第 1～4 格輸出，簡短回報：
   - 第 1 格：GPU／記憶體／磁碟（實測：RTX PRO 6000 96GB、177GB RAM、193GB 磁碟）。
   - 第 3 格：`Downloading…` → `Checking…` → `Loading the model…` → `✅ 模型載入完成`（實測約 10 分鐘）。
   - 第 4 格：文件工具自我檢查，每項 ✅／❌，最後「✅ 全部通過」。有 ❌ 不擋啟動，但要在交棒時告訴老師哪項功能可能不能用。
   - 出現 `❌` 或 Traceback → 停止，摘要錯誤並對照 README 的「疑難排解」；問老師要不要刪除主機以免空轉扣單元。
4. 記下開始時間（用來估算單元）。

## C. 交棒給老師

用 JavaScript 確認第 5 格輸出區域裡有 1 個 iframe（入口已出現）後，**立刻停止操作瀏覽器**，不要再捲動到第 ⑤ 格或截圖（實測：老師常在入口出現後馬上開始用，截圖會拍到對話內容）。告訴老師：

- 老師想用自己的 Chrome（預設瀏覽器）時，改用 Claude in Chrome（`mcp__claude-in-chrome__*`）跑同樣流程；連了多個 Chrome 時用 `switch_browser` 讓老師在正在用的那個按 Connect，不要猜。

- 對話框就在瀏覽器窗格裡、第 ⑤ 格下方，直接打字（已預先開好「工作區」專案；若仍看到專案首頁，按「新增專案」→ `/content/工作區/` → 「新增工作階段」）。
- 檔案：對話框左下「＋」附加。所有檔案（附加的、AI 產出的）都在「工作區」這一個資料夾。
- 想直接看檔案：按「👀 檢視工作區檔案」格的 ▶，選檔案按「顯示」（Word／PPT 逐頁、Excel 表格、PDF、圖片都能看，不必下載；可單檔下載）。筆記本設定不儲存輸出，內容不會存回雲端硬碟。
- 要帶走結果：按「⬇️ 下載結果」格的 ▶，整個工作區打包成 zip。
- 思考強度：入口可切換 off／low／medium／high（off 最快；寫 IEP、分析用 high）。第 ⑤ 格會印出是否確認生效。
- 對話很長時 OpenCode 會在用到 80% 時自動壓縮前面的內容，不會爆掉。
- 入口上方那格顯示紅色停止標記是正常的（讓「全部執行」停在那裡）。
- 建議先把學生姓名等換成代號；不要用 Colab 的 Gemini。
- 用完說「私人 AI 用完了」，我會清理、刪除主機並確認不再扣單元。

## D. 關閉

1. 若窗格已關：`preview_start` 開筆記本網址（會回到同一台主機）。
2. `find`「程式碼儲存格：🧹」→ `scroll_to` → 截圖 → 點該格左邊的 ▶（v3 起沒有核取方塊；**舊版 v2 有「確定清理」方框，勾選狀態會被存進筆記本，清理後務必取消勾選**）。
3. 約 5 秒後讀最後一格輸出，確認「✅ 已關閉 AI、刪除工作區、對話紀錄與日誌」。
4. `find`「執行階段」→ 點選單 → `find`「中斷連線並刪除執行階段」→ 點擊 → 截圖，點確認對話框藍色「是」。
5. `zoom` 工具列右上：顯示「重新連線／連線」、狀態列不再顯示 G4。

## E. 確認不再扣單元

1. `find`「執行階段」→ 開選單 → `find`「管理工作階段」→ 點擊 → 截圖。
2. 看到「沒有作用中工作階段」→ 按 Esc，關閉分頁（`tabs_close`）。
   - 還有工作階段 → 回到 D 第 4 步或在對話框按「終止」（老師要求關閉即表示同意）。
3. 回報：使用時間與估計單元數（G4 ≈ 8.7／小時），並提醒「只關分頁不會停止扣單元，以後都說『私人 AI 用完了』讓我收尾」。
4. 若老師的專案有使用紀錄檔，記下本次使用時間與估計單元數。
