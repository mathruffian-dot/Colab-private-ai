# 🔒 教師私人 AI（Colab 版）

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/mathruffian-dot/Colab-private-ai/blob/main/%E5%95%9F%E5%8B%95%E7%A7%81%E4%BA%BAAI.ipynb)

讓**沒有高階顯示卡的老師**，也能用「自己的私人主機＋本地 AI」處理含學生個資的教學資料（特教 IEP、輔導紀錄、成績分析、通知單……）。

- AI 模型（Strata＋Qwen3.8-Flash-Next）跑在**你自己 Google 帳號的 Colab 私人主機**上，學生資料不會送到任何 AI 公司。
- 在網頁對話框跟 AI 對話、附加檔案、請它整理或產出文件，結果可以直接在 Colab 裡看，也可以下載。
- 用完刪除執行階段，主機連同所有檔案、對話紀錄一起銷毀。

## 你需要準備的

- 一個有**付費 Colab 運算單元**的 Google 帳號（Google AI Pro 方案內含，或 Colab Pro）。免費版跑不動。
- 一般電腦和 Chrome 瀏覽器。不用安裝任何軟體，也不需要 GitHub 帳號。
- 費用：使用的是**你自己的**運算單元，G4 主機每小時約 8.7 單元。

## 使用方式（四步驟）

1. **開啟**：按上面的「Open in Colab」按鈕。
2. **啟動**：選單「執行階段 → 全部執行」。
   - 跳出「這個筆記本不是由 Google 編寫的」→ 按「仍要執行」。
   - 跳出「啟用 AI 自動完成」→ 按 ✕（那是 Gemini，不要用）。
3. **使用**：約 10 分鐘後，第 ⑤ 格下方會出現對話框，直接打字。
   - 檔案：按對話框左下的「＋」附加。你附加的、AI 產出的檔案都放在「工作區」。
   - 看檔案：按「👀 檢視工作區檔案」格左邊的 ▶，選檔案按「顯示」，Word、Excel、PowerPoint、PDF、圖片都能直接看，不必下載。
   - 帶走結果：按「⬇️ 下載結果」格的 ▶，整個工作區打包成 zip；或在檢視格按「下載這個檔案」只下載一個。
   - 思考強度：對話框可切換 off／low／medium／high。整理表格、轉檔用 off 最快；寫 IEP、分析學生狀況用 high。
   - 「⏹ 啟動完成」格出現紅色停止標記是正常的。
4. **關機（一定要做）**：按「🧹 清理」格的 ▶，再按選單「執行階段 → 中斷連線並刪除執行階段」→「是」。
   - **只關分頁不會停止扣單元。** 不放心可以到「執行階段 → 管理工作階段」，看到「沒有作用中工作階段」就對了。

## AI 已經會做的事

開機時會自動裝好下列工具，並在第 ④ 格做一次自我檢查（20 項，每項顯示 ✅／❌）：

| 你想做的 | 例如 |
|---|---|
| Word／Excel／PowerPoint | 讀寫、轉 PDF；Word 表格、Excel／PPT 可再編輯的原生圖表 |
| 合併列印 | 用 Word 範本為每位學生產生一份通知單、成績單 |
| 圖表 | 統計圖、互動圖表、流程圖、組織圖（中文不會變方塊） |
| PDF | 讀取文字與表格、合併、分割、加密碼 |
| 掃描檔與圖片 | 繁中文字辨識（OCR）、掃描 PDF 轉成可搜尋文字；AI 也能直接看圖 |
| 有密碼的檔案 | 打開學校寄來有密碼的 Excel／Word（由你提供密碼）、加密壓縮 |
| 學校文件格式 | 標楷體、新細明體自動用最接近的楷書、明體；舊版 .xls／.doc |
| 文字處理 | 簡體轉繁體（台灣用語）、輔導紀錄或問卷開放題的關鍵字分析、文字雲、注音、去識別化 |
| 語音 | 會議、晤談錄音轉逐字稿（**離線**，含個資可用）；文字轉語音（台灣口音，**線上服務，只能用於不含個資的文字**） |
| 影音與其他 | 影片／音訊轉檔、剪輯、壓縮（FFmpeg）、圖片批次縮放、QR code、zip／7z／rar 壓縮檔 |

- 上下文 256K，用到 80% 會自動壓縮前面的內容，長對話不會爆掉。

## 隱私須知

- 上傳前建議先把學生姓名、身分證字號、生日等換成代號；也可以請 AI 幫你去識別化，再自己確認。
- **不要使用 Colab 裡的 Gemini 功能**處理學生資料。
- 文字轉語音（edge-tts）會把文字送到微軟的線上服務，AI 會先問過你，而且只用在不含學生個資的內容。
- 筆記本設定為「不儲存輸出」：畫面上看到的內容不會存回你的雲端硬碟。
- 入口只有你這個瀏覽器、這個 Google 帳號看得到；另開分頁或換瀏覽器會是 404，這是 Colab 的保護。
- 資料在使用期間會暫時放在 Google 的機房（可能在國外），請依學校規範使用。

## 疑難排解

| 狀況 | 原因與處理 |
|---|---|
| 第 ① 格說沒有 GPU | 「執行階段 → 變更執行階段類型」選 G4，再重新全部執行。 |
| 入口顯示 404 | 入口只能在跑這本筆記本的同一個分頁使用，不要另開分頁或換瀏覽器。 |
| 第 ④ 格自我檢查有 ❌ | AI 仍可使用，只是那項功能可能要改用別的方式；可以回報到本 repo 的 Issues。 |
| 關掉分頁後還在扣單元 | 回到筆記本按「執行階段 → 中斷連線並刪除執行階段」，或在「管理工作階段」終止。 |

## 讓 AI 助理幫你全部做完（進階）

如果你有會操作瀏覽器的 AI 助理，可以讓它代勞開機、等待、關機與確認不再扣單元：

- **Claude Code**：把 [`skills/private-ai-colab/`](skills/private-ai-colab/) 複製到你專案的 `.claude/skills/`，說「**啟動私人 AI**」；用完說「**私人 AI 用完了**」。
- **其他 agent**（Antigravity、Gemini CLI 等）：請它閱讀並依照 [`AGENTS.md`](AGENTS.md) 執行。

你只需要親自做兩件事：登入 Google、第一次按 Colab 服務條款的「同意」。AI 助理交出入口後不會再看你的畫面。
